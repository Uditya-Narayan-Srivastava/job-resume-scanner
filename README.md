# Job Resume Scanner

A Streamlit-based mini project that analyzes resumes and provides useful insights based on the uploaded resume and job requirements.

## Features

* Upload and analyze resumes
* Extract relevant resume information
* Analyze skills and experience
* Compare resume information with job requirements
* Simple and interactive Streamlit interface

## Tech Stack

* Python
* Streamlit
* Pandas
* NLP / Text Processing
* PDF Processing

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/job-resume-scanner.git
```

Move into the project directory:

```bash
cd job-resume-scanner
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate it on Windows:

```powershell
.venv\Scripts\activate
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

## Run the Application

Start the Streamlit application using:

```bash
streamlit run job_resume_scanner.py
```

The application will open in your browser.
